# Zen Tidy Tabs 0.8.0

Tidy групує вільні вкладки поточного простору за темами. Кнопка з’являється у штатному сепараторі Zen від п’яти вільних вкладок.

## Оновлення з 0.7.1

Заміни `tidy-tabs.uc.js` у папці мода та повністю перезапусти Zen. Можна використовувати раніше вибраний `zen-tidy-apple` від 0.7.1. Після оновлення натисни Tidy один раз, щоб записати групи в сесію.

## Керування

- Перетягни вільну вкладку на назву групи або на одну з її вкладок. Можна також перенести вкладку з іншої тимчасової групи.
- Потягни заголовок групи на верхню чи нижню половину іншої групи, щоб змінити їх порядок. Лінія показує місце вставлення.
- Перетягни заголовок групи в закріплену область над сепаратором або на сам сепаратор, щоб створити нативну папку.
- Правий клік на заголовку відкриває текстові команди **Create pinned folder** і **Close group**.
- Нові вкладки з’являються над групами. Їх можна додати вручну або наступним натисканням Tidy.
- Групи та ручні переміщення відновлюються разом із вкладками сесії Zen. Вкладки з однаковими адресами можуть належати до різних груп.

## Групування

Apple Intelligence працює на Mac із Apple Silicon, macOS 26 або новішою, увімкненим Apple Intelligence та завантаженою системною моделлю. Помічник отримує назви та очищені адреси локально після натискання Tidy. Підтримується до 40 вкладок. Відомі сервіси й тематичні ознаки уточнюють результат моделі, зокрема для AI, Design і Gaming.

Правий клік на Tidy дозволяє вибрати **Use Apple Intelligence**, **Apple Intelligence helper…** або **Use local rules**. Ключі API й оплата за запити не потрібні.

## Перше встановлення

Розпакуй архів у постійну папку. Потрібен завантажувач userChromeJS, наприклад [fx-autoconfig](https://github.com/MrOtherGuy/fx-autoconfig), або [Sine](https://github.com/CosmoCreeper/Sine). Помісти скрипт у `chrome/JS` профілю з fx-autoconfig чи папку мода Sine і перезапусти Zen. При першому натисканні Tidy вибери файл `apple-intelligence/zen-tidy-apple`. Для режиму локальних правил достатньо скрипта.

Swift-код помічника міститься поруч із виконуваним файлом. Походження іконки описано в `ATTRIBUTION.md`.
