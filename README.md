# Zen Tidy Tabs — 0.5.0

Tidy у нативному сепараторі Zen групує вільні вкладки поточного простору за назвою та сайтом. Усе працює локально, без ШІ та мережевих запитів мода.

## Оновлення

Заміни старий `tidy-tabs.uc.js` новим у тому самому місці — `chrome/JS` або папці цього мода в `chrome/sine-mods` — та повністю перезапусти Zen. Не залишай другу копію старого скрипта. SVG вбудовані в JavaScript: додаткові файли для запуску не потрібні.

Для першого встановлення потрібен завантажувач userChromeJS/fx-autoconfig або Sine. Саме створення папки chrome/JS не встановлює завантажувач.
- fx-autoconfig: https://github.com/MrOtherGuy/fx-autoconfig
- Sine: https://github.com/CosmoCreeper/Sine

З установленим fx-autoconfig скопіюй скрипт у chrome/JS активного профілю (about:support → Profile Folder). Для встановлення через поле репозиторію Sine розмісти пакет у власному GitHub-репозиторії та додай його адресу в Sine. У магазині цей пакет не опублікований.

## Поведінка

- Tidy доступний від 5 вільних незакріплених вкладок поточного простору.
- Групи утворюються від двох вкладок. Поодинокі залишки збираються в Other; один залишок стоїть окремо.
- Нові вкладки, включно з відкритими під час анімації, стоять над групами до наступного Tidy. Закриття чи створення папки з наявної групи їх не зачіпає.
- Кнопка папки створює нативну закріплену папку Zen. Хрестик закриває лише вкладки відповідної групи.
- Clear залишається штатною командою Zen зі стандартними правилами браузера.
- Закріплені вкладки, Essentials, вкладки всередині нативних папок/груп/split view та інших просторів не групуються.
- Тимчасові заголовки не зберігаються після перезапуску. Створені нативні папки зберігає Zen.
- Назви й підказки мода англійською. Правила змінюються в RULES на початку скрипта.

## Зміни 0.5.0

- Мітла — SVG-переклад векторного малюнка DiaTweaks Brush.m. Атрибуція в ATTRIBUTION.md.
- Папка й хрестик — нові надані користувачем SVG. Хрестик залишається 9 × 9 px із більшою областю натискання.
- Назви груп плавно з’являються протягом 420 мс із невеликим зсувом і затримкою між групами.
- Анімація назв запускається тільки після Tidy. Звичайні оновлення панелі повторно використовують наявні заголовки: відкриття закріпленої папки більше не викликає появу назв заново.
- Хвилька перетворює лінію на синусоїду й повертає її назад протягом 900 мс. Системне reduced motion вимикає анімації.

У DiaTweaks створення та показ назв виконує сам Dia; окремої реалізації анімації тексту в переглянутому коді TidyTabs немає. У цьому моді використана власна анімація назв для Zen, а не перенесення внутрішньої анімації Dia.

## Перевірки

39 перевірок правил (`node test.cjs`) і 38 інтеграційних перевірок у headless Zen 1.24b: іконки, поріг 4/5, колір, суцільний сепаратор, хвилька, нові вкладки, папки, закриття, збереження DOM заголовків та відсутність повторної анімації при розгортанні закріпленої папки.

Основний профіль користувача не змінювався. Стилі сторонніх модів можуть впливати на вигляд. Для видалення прибери скрипт і перезапусти Zen; створені папки залишаться.
