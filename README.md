# Zen Tidy Tabs — 0.1.0

Мод для Zen: кнопка **Tidy** перетворює вільні вкладки поточного простору на тимчасові групи із заголовками, як в Arc. Усе обчислюється локально за адресою та назвою вкладки, без ШІ, API-ключів і мережевих запитів від мода.

## Керування

- **Tidy** — згрупувати вкладки; під час сортування лінія перетворюється на рухому хвильку.
- **Clear** — закрити всі вільні вкладки поточного простору.
- **⊞** біля назви групи — створити нативну папку Zen. Zen закріплює її вкладки.
- **×** біля назви групи — закрити вкладки цієї групи.
- **↶** — прибрати тимчасові заголовки й повернути початковий порядок вкладок, які ще відкриті.

Кнопки групи з’являються при наведенні або клавіатурному фокусі. Закриття використовує механізм Zen, включно з попередженнями сторінок про незбережені дані. Закриті вкладки можна відновлювати звичайною командою браузера Cmd/Ctrl+Shift+T; ↶ скасовує лише сортування.

Закріплені вкладки, Essentials, вкладки всередині папок/нативних груп/split view та інших просторів не беруть участі. Нові вкладки залишаються поза групами до наступного натискання Tidy. Тимчасові заголовки живуть до перезапуску браузера; створені папки зберігає Zen. Системне налаштування reduced motion вимикає анімації.

## Установлення

Це JavaScript-мод, а не CSS-тема і не XPI-розширення. Самого userChrome.css недостатньо.

### Якщо вже є завантажувач userChromeJS / fx-autoconfig

1. У Zen відкрий `about:support` → **Profile Folder / Папка профілю** → **Show in Finder / Відкрити папку**.
2. Скопіюй `tidy-tabs.uc.js` у `chrome/JS/` цього профілю.
3. Повністю закрий і знову відкрий Zen. Якщо завантажувач кешує скрипти, очисть його startup cache за його інструкцією.
4. Розгорни бічну панель: над вільними вкладками має бути Tidy / Clear.

Саме створення папки chrome/JS не встановлює завантажувач. Установлення fx-autoconfig описане в його офіційному репозиторії: https://github.com/MrOtherGuy/fx-autoconfig.

### Через Sine

Пакет містить `theme.json` для Sine. Для встановлення через поле репозиторію потрібно спершу розмістити вміст цієї папки у власному GitHub-репозиторії, а потім додати його адресу у Settings → Sine Mods. Для неопублікованого JavaScript-мода може знадобитися дозвіл JS з неофіційних джерел у налаштуваннях Sine. Цей пакет ще не опубліковано в магазині чи GitHub.

Офіційні інструкції Sine: https://github.com/CosmoCreeper/Sine.

Для видалення постійної установки прибери `tidy-tabs.uc.js` із chrome/JS і перезапусти браузер або видали мод через Sine. Створені папки при цьому залишаються.

## Правила

На початку `tidy-tabs.uc.js` є масив `RULES`. Перше відповідне правило виграє: Arc → Apple → Дизайн → Розробка → Ігри → Відео й музика → Покупки. Перевіряються точні домени та їхні піддомени, окремі слова/фрази в заголовку й пошуковий запит Google/Bing/DuckDuckGo. Наприклад, відео YouTube про Arc потрапить до Arc, а не до загальної групи відео.

Решта HTTP(S)-вкладок групуються за базовим доменом через Mozilla Public Suffix List; службові сторінки — в «Інше». Навіть одна вкладка може утворювати групу. Назви, домени та ключові слова можна змінювати в RULES.

## Сумісність

Розроблено з перевіркою API установленого Zen 1.24b. Це рання версія: Zen використовує внутрішні API, які можуть змінитися після оновлення. Одночасне використання з іншим модом, що сортує ті самі вкладки, не перевірено. Власний профіль користувача не змінювався.

## Перевірки цієї збірки

- 23 автоматичні перевірки класифікації та відбору вкладок; запуск: `node test.cjs`.
- В окремому headless-профілі Zen 1.24b пройшли 11 інтеграційних перевірок: поява панелі й заголовків, сусідство вкладок однієї теми, збереження закріплених вкладок, прибирання заголовків і відновлення порядку через Undo, наявність тематичної групи, створення нативної папки, закриття вільних вкладок, збереження папки та закріплених вкладок після Clear, очищення UI через destroy.
- Візуальний вигляд у твоєму профілі з іншими темами та модами не перевірявся. Анімація реалізована в CSS; плавність у видимому вікні ще потребує перевірки.
