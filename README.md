# Zen Tidy Tabs — 0.7.1

Групування вкладок локально через Apple Intelligence. Без API-ключа, оплати за запити або фонового сервера. Помічник використовує `SystemLanguageModel.default` з Apple Foundation Models; запускається лише на час Tidy.

## Установлення на Mac з Apple Silicon

Потрібна macOS 26 або новіша, увімкнений Apple Intelligence і завантажена системна модель. У System Settings → Apple Intelligence & Siri перевір доступність моделі. Самого процесора M2 недостатньо без підтримуваної системи та налаштувань мови.

1. Розпакуй **весь** архів у постійну папку. Не запускай файли всередині ZIP.
2. При оновленні з 0.7.0 заміни також файл `apple-intelligence/zen-tidy-apple` за збереженим шляхом або вибери новий через **Apple Intelligence helper…**. Заміни попередній `tidy-tabs.uc.js` у папці мода Sine або `chrome/JS` активного профілю. Не залишай дві копії. Повністю перезапусти Zen.
3. Відкрий щонайменше 5 вільних вкладок і натисни **Tidy**.
4. У вікні вибору файла вибери **apple-intelligence/zen-tidy-apple** із розпакованої папки. Це потрібно один раз; шлях зберігається в налаштуваннях Zen.
5. Наступні натискання Tidy використовують локальну модель автоматично.

У цьому оновленні двигун один раз перемикається з попереднього режиму на Apple Intelligence. Збережений OpenAI-ключ не видаляється і в Apple-режимі не використовується.

Правий клік на Tidy: **Apple Intelligence helper…** — вибрати помічник знову; **Use Apple Intelligence**, **Use OpenAI**, **Use local rules** — вибрати двигун. Якщо перенесеш папку помічника, вибери його знову.

Для першого встановлення потрібен завантажувач [fx-autoconfig](https://github.com/MrOtherGuy/fx-autoconfig) або [Sine](https://github.com/CosmoCreeper/Sine). Саме створення папки `chrome/JS` його не встановлює. Розташування профілю: `about:support` → Profile Folder. Пакет у магазині Sine не опублікований. Помічник треба зберегти окремо і вибрати навіть при встановленні скрипта через Sine.

## Дані та обмеження

Локальному помічнику через stdin передаються тільки назви та адреси вільних вкладок поточного простору. Із URL видаляються query, fragment, логін і пароль. Сторінки, cookies та історія не читаються. Мод не надсилає ці дані в мережу в Apple-режимі. Модель Apple може потребувати початкового системного завантаження.

До 40 вкладок за один запуск; назви обмежено 100 символами, URL — 120. Тайм-аут 60 секунд. Короткі англійські назви груп генерує модель, тематична якість може відрізнятись між запусками та версіями macOS. Випадкові або нечіткі назви можуть класифікуватися помилково; перевір групу перед закриттям. Apple Intelligence спочатку обирає спільні широкі теми, потім розподіляє вкладки між ними. Групи містять принаймні дві вкладки; сторінки без чіткої теми та одиночні теми об’єднуються в Other. Якщо залишилася лише одна така вкладка, вона лишається над групами. Помилка залишає наявний порядок і групи незмінними. Автоматичного переходу на хмарний API немає.

## Поведінка

- Tidy з’являється від 5 вільних вкладок у нативному сепараторі поруч зі штатним Clear.
- Хвиля триває, доки модель працює. Після Tidy коротка сіра смужка змінюється назвою з кольоровим відблиском по тексту, як у відео. Розгортання групи чи закріпленої папки не повторює ефект.
- Нові вкладки одразу з’являються над групами. Вони не потрапляють у групи до наступного Tidy, включно з вкладками, відкритими під час генерації.
- Закріплені вкладки, Essentials, нативні папки/групи/split view та інші простори виключені.
- Натискання заголовка або шеврона згортає/розгортає вкладки групи. Заголовок залишається видимим. Enter і Space працюють із клавіатури.
- Правий клік на заголовку → **Create pinned folder** або **Close group**. Окремі кнопки папки й хрестика біля назви прибрано.
- Нові вкладки не ховаються разом зі згорнутою групою. Вибір прихованої вкладки через браузер розгортає її групу.
- Тимчасові групи не зберігаються після перезапуску; нативні папки зберігає Zen.
- Reduced motion вимикає анімації.

## Інші двигуни

**Use local rules** працює без ШІ та без помічника. **OpenAI settings…** налаштовує модель і ключ, який зберігається в менеджері паролів Zen (`https://zen-tidy-tabs.invalid`, realm `OpenAI API`; це ідентифікатор, а не адреса запитів). **Forget API key** видаляє його.

Лише в OpenAI-режимі натискання Tidy надсилає назви й очищені адреси вкладок на `https://api.openai.com/v1/responses`; потрібен API-баланс, до 80 вкладок, тайм-аут 30 секунд. Використовується `store:false`, що не гарантує відсутності всіх серверних журналів.

## Збірка помічника

Бінарний файл у пакеті зібраний для arm64 / macOS 26+. Вихідний Swift-код поруч. Для власної збірки потрібен Swift SDK із FoundationModels:

```sh
swiftc -parse-as-library -O -target arm64-apple-macos26.0 apple-intelligence/ZenTidyApple.swift -o apple-intelligence/zen-tidy-apple
```

[Apple Foundation Models](https://developer.apple.com/documentation/foundationmodels). Іконки та походження анімацій: `ATTRIBUTION.md`.

Для видалення прибери скрипт та папку помічника й перезапусти Zen. Створені нативні папки залишаться.

## Попередні перевірки (0.7.0)

58 перевірок правил, очищення URL, валідації JSON та API-помилок. 47 інтеграційних перевірок у Zen 1.24b з окремим тестовим профілем, включно з реальним викликом Apple Intelligence через subprocess на macOS 27.2. На вигаданих вкладках отримано Gaming, Design і Space; хмарний fetch у цьому тесті був заблокований. Перевірено вставку нових вкладок, хвилю, нативні папки, Clear та збереження порядку при помилці API. Основний профіль користувача не змінювався.

## Перевірено у 0.7.1

58 unit assertions і 14 перевірок оновленої поведінки в окремому Zen-профілі: реальний локальний виклик Apple Intelligence, спільні Design/UX та SpaceX/NASA, Other для домашньої YouTube і числового пошуку, кольоровий відблиск, завершення анімації, згортання/розгортання, нові вкладки над згорнутими групами, обидві дії контекстного меню та повернення прихованих вкладок при видаленні мода. Випадковий текст одного пошуку модель усе ще віднесла до Design: семантична класифікація не гарантує точності для нечітких назв.
