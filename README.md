# Zen Tidy Tabs — 0.6.0

Групування вкладок через OpenAI з назвами груп англійською, хвилькою у нативному сепараторі та створенням папок Zen. Доступний також режим локальних правил без мережі.

## Увімкнути OpenAI

1. Заміни старий `tidy-tabs.uc.js` новим і повністю перезапусти Zen.
2. Відкрий щонайменше 5 вільних вкладок, щоб з’явилася Tidy.
3. Натисни Tidy: при першому запуску мод попросить модель (типово `gpt-4.1-mini`) та API-ключ OpenAI.
4. Надалі правий клік на Tidy відкриває меню: **OpenAI settings…**, **Use OpenAI**, **Use local rules**, **Forget API key**.

Ключ зберігається в менеджері паролів Zen як запис для `https://zen-tidy-tabs.invalid`, realm `OpenAI API`. Ця адреса є ідентифікатором запису, мережеві запити на неї не виконуються. Не вставляй ключ у код чи чат.

За натисканням Tidy мод надсилає назви й адреси вільних вкладок поточного простору на `https://api.openai.com/v1/responses`. Із URL прибираються логін, пароль, query та fragment; текст сторінок, cookies та історія не надсилаються. Назва вкладки може сама містити пошуковий запит. API використовує твій обліковий запис OpenAI та його API-баланс. Запит має `store:false` (це не гарантія відсутності всіх серверних журналів).

Ліміт — 80 вкладок, timeout — 30 секунд. Хвилька рухається, поки триває запит. Некоректна відповідь або помилка API залишає групи та порядок незмінними; автоматичної підміни ШІ правилами немає. **Use local rules** явно перемикає мод на локальне групування.

## Оновлення

Заміни старий `tidy-tabs.uc.js` новим у тому самому місці — `chrome/JS` або папці цього мода в `chrome/sine-mods` — та повністю перезапусти Zen. Не залишай другу копію старого скрипта. SVG вбудовані в JavaScript: додаткові файли для запуску не потрібні.

Для першого встановлення потрібен завантажувач userChromeJS/fx-autoconfig або Sine. Саме створення папки chrome/JS не встановлює завантажувач.
- fx-autoconfig: https://github.com/MrOtherGuy/fx-autoconfig
- Sine: https://github.com/CosmoCreeper/Sine

З установленим fx-autoconfig скопіюй скрипт у chrome/JS активного профілю (about:support → Profile Folder). Для встановлення через поле репозиторію Sine розмісти пакет у власному GitHub-репозиторії та додай його адресу в Sine. У магазині цей пакет не опублікований.

## Поведінка

- Нові вкладки одразу вставляються над групами через позицію створення Zen, без відкладеного перенесення. Нативні папки, pinned та Essentials не перехоплюються.
- Нові вкладки не входять до вже створених груп до наступного Tidy. Вкладки, відкриті під час запиту, теж залишаються окремими.
- ШІ створює тематичні групи від двох вкладок; непов’язані вкладки залишаються без групи. Локальний режим залишає попередні правила з Other.
- Кнопка папки створює нативну закріплену папку Zen; хрестик закриває лише членів групи. Clear лишається штатною командою Zen.
- Папка й хрестик мають товстіші контури; хрестик збережений у розмірі 9 px.
- Відкриття закріпленої папки не повторює анімацію назв. Нові назви анімуються лише після Tidy. Reduced motion вимикає анімації.
- Закріплені вкладки, Essentials, вкладки всередині нативних груп/папок/split view та інших просторів виключені з Tidy.
- Тимчасові групи не зберігаються після перезапуску. Нативні папки зберігає Zen.

## Перевірки

51 перевірка правил, очищення URL та валідації AI JSON (`node test.cjs`). 46 інтеграційних перевірок у headless Zen 1.24b, включно з миттєвою вставкою, відновленням перехопленого методу при видаленні мода, сховищем ключа, форматом Responses-запиту, групуванням за тестовою відповіддю та незмінністю вкладок при HTTP 401.

Реальний OpenAI-запит не виконувався: тестовий транспорт повертав локальні відповіді без справжнього ключа та мережевого надсилання вкладок. Після введення власного ключа перевір реальну якість тематичного групування.

https://developers.openai.com/api/docs/guides/structured-outputs?api-mode=responses
https://developers.openai.com/api/docs/models/gpt-4.1-mini
