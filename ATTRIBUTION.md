# Icon attribution

The broom SVG is a translation of the vector drawing in DiaTweaks `Brush.m` by JaceThings and contributors:
https://github.com/JaceThings/DiaTweaks/blob/main/src/dylib/Patches/TidyTabs/Brush.m

The folder and close SVGs were supplied by the user (SF Symbols exports). Their geometry is preserved; CSS sets their displayed sizes and theme color.

The five create-menu glyphs are Apple SF Symbols rendered through AppKit at medium weight.

Folder uses the official kubai-icons 0.3.1 package, including its SVG, filters, gradients and animation runtime (MIT). https://www.npmjs.com/package/kubai-icons. See KUBAI-LICENSE.txt.
